# Dependencies
Most package versions required for analysis can be installed into a conda environment using the complete_env.yml file. Additionally, within the R environment, the following packages should be installed: alakazam 1.4.3, sHazaM 1.3.2, tigger 1.1.3, SCOPer 1.5.0, dowser 2.4.1, harmony v2.0.5, presto v.1.0.0, hdf5r v1.3.12, BiocManager v1.30.27, and escape v2.6.2.
